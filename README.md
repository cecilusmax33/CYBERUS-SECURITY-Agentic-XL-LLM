# CYBERUS SECURITY — Metasploit Module Metadata

A snapshot of `modules_metadata.json`: the module index generated by the [Metasploit Framework](https://github.com/rapid7/metasploit-framework), covering **6,058 modules**.

This is reference data — names, descriptions, authors, references (CVEs/advisories), platforms, ranks, and options metadata for every module. It does **not** contain module source code or exploit code itself.

## Contents

| File | What it is |
| --- | --- |
| `modules_metadata/part-001.json` … `part-008.json` | The full metadata set, sharded: one JSON object per part, keyed by module path (e.g. `exploit_windows/smb/ms17_010_eternalblue`), 26 metadata fields per module, keys sorted across parts |

The original export is a single `modules_metadata.json` (~9.7 MB) — too large for one upload here, so it is stored as 8 shards. Merging them reproduces the original file's data exactly (verified: 6,058 modules, round-trip identical).

```bash
# Rebuild the single-file modules_metadata.json
python3 -c "
import json, glob
merged = {}
for f in sorted(glob.glob('modules_metadata/part-*.json')):
    merged.update(json.load(open(f)))
json.dump(merged, open('modules_metadata.json', 'w'), indent=1, sort_keys=True)
print(len(merged), 'modules')
"
```

## Quick use

```bash
# Count modules across all shards
python3 -c "
import json, glob
n = sum(len(json.load(open(f))) for f in glob.glob('modules_metadata/part-*.json'))
print(n)
"

# List every module that targets a given platform
python3 -c "
import json, glob
for f in sorted(glob.glob('modules_metadata/part-*.json')):
    for k, v in json.load(open(f)).items():
        if 'windows' in (v.get('platform') or '').lower():
            print(k, '-', v['name'])
"
```

Search it with `jq`, load it into a database, or diff it against a newer export to see what modules changed between Metasploit versions.

## Notes

- This file is normally generated locally by Metasploit (`msfconsole` builds it in `~/.msf4/store/modules_metadata.json`) and is regenerated as modules are added or updated — treat this repo as a dated snapshot, not a live mirror.
- Author email addresses appearing in the `author` fields are the module authors' own publicly published contacts, as shipped in Metasploit's source.
- Data originates from the open-source Metasploit Framework (Rapid7); see that project for licensing.
